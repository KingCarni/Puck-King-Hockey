# Puck King Hockey Roadmap

## Phase 0 - Project Foundation

Goal: create the repo/project foundation and design spine.

Deliverables:

- README
- Game design document
- Vertical slice document
- Godot project setup
- Base folder structure
- Input map
- Test rink scene placeholder

## Phase 1 - Core Hockey Feel

Goal: prove movement, puck, shot, and hit feel.

Deliverables:

- Player skating controller
- Loose puck physics
- Puck possession
- Shooting
- Goal scoring
- Checking
- Basic HUD

Exit criteria:

- One player can skate, pick up puck, shoot, score, and check a dummy/opponent.

## Phase 2 - Playable Match

Goal: complete a simple match loop.

Deliverables:

- 3v3 teams
- Basic AI
- Goalie prototype
- Score/time rules
- Goal reset
- Win/loss screen

Exit criteria:

- First-to-3 match can be played from start to finish.

## Phase 3 - Roguelite Hook

Goal: connect one match to one reward choice.

Deliverables:

- Reward draft screen
- Upgrade data model
- Three initial upgrades
- Apply upgrade to team/player stats
- Continue button placeholder

Exit criteria:

- Player wins match, selects upgrade, and sees it applied.

## Phase 4 - RPG Roster Identity

Goal: make players feel like characters.

Deliverables:

- Player names
- Classes
- Stats
- Traits
- XP placeholder
- Injury/fatigue placeholders

Exit criteria:

- Roster members have identity and stats that affect gameplay.

## Phase 5 - Run Map Prototype

Goal: create the broader roguelite loop.

Deliverables:

- Branching run map
- Match nodes
- Event nodes
- Shop/heal placeholder
- Boss node placeholder

Exit criteria:

- Player can move through a short run path with match and reward nodes.

## Phase 6 - Content Expansion

Goal: add enough variety to test replayability.

Deliverables:

- 3 enemy teams
- 10+ upgrades
- 10+ traits
- 5+ events
- 1 boss team
- Basic balancing pass

## Phase 7 - Prototype Polish

Goal: make the prototype presentable.

Deliverables:

- Better UI
- Placeholder art pass
- Sound pass
- Hit/goal juice
- Tutorial hints
- Pause/settings

## Not Before Core Feel Is Proven

Avoid these until the base match is fun:

- Online multiplayer
- Deep season mode
- Full custom team editor
- Realistic rules/penalties
- Complex stat simulation
- Marketplace/cosmetics
- Console planning
