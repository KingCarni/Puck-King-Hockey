# Puck King Hockey

Chaotic arcade hockey meets roguelite RPG progression.

## Core Concept

Puck King Hockey is a fast, messy, high-impact hockey roguelite where every run builds a team story. Matches should feel arcade-first: quick skating, big hits, ridiculous upgrades, short games, and memorable players.

## Initial Vertical Slice

The first playable target is a simple 3v3 arcade hockey match:

- One test rink
- Player skating
- Puck possession and loose puck physics
- Shooting and scoring
- Body checking and puck loss
- Basic opponent AI
- First-to-3 win condition
- Post-match upgrade draft prototype

## Development Priorities

1. Make movement feel good.
2. Make puck control readable and satisfying.
3. Make hits funny, chaotic, and useful.
4. Add the roguelite layer only after the match loop is fun.

## Tech Direction

Godot-first prototype, PC-first target.
